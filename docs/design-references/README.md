## Usage

- Treat these files as art-direction targets, not production image assets.
- Preserve each image's aspect ratio. The listed dimensions describe the stored reference image, not necessarily its original browser viewport or export scale.
- Do not overwrite an approved reference. Add a clearly named revision when the visual direction changes.
- Runtime brand artwork belongs in `public/brand/`; canonical design references remain in this directory.
